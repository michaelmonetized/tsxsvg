# tsxsvg

Convert SVG files to optimized React/TypeScript components.

> ⚠️ **Early concept stage** — see [PLAN.md](./PLAN.md) for the development roadmap.

## Planned Features

- SVG → TSX component conversion with proper TypeScript types
- SVGO optimization built-in
- Batch conversion for icon libraries
- CLI interface for CI/CD pipelines
- Support for dynamic props (color, size, className)

## Tech Stack

- TypeScript
- SVGO for optimization
- CLI via Commander or similar

## Status

This project is in the planning phase. Contributions and ideas welcome — [open an issue](https://github.com/michaelmonetized/tsxsvg/issues).
